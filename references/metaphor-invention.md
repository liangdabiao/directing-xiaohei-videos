# 隐喻发明法（每个场景必须重新发明）

## 三步法

1. **抽象概念 → 物理动作**：卡住、漏掉、变重、分拣、沉淀、发酵、开门、折叠、拆包、回流、融化、膨胀、蒸发、排队、越位。
2. **系统结构 → 低科技物件**：坏掉的机器、纸箱、抽屉、漏斗、秤、邮筒、井、梯子、水管、传送带、闸门、转盘、黑盒、晾衣绳、怪工位、存钱罐、冰格。一场只用 1–2 个物件，不堆满。
3. **小黑承担动作**：不是站旁边解说，而是卡在机器里、拉错线、守门、搬运、修补、称重、把东西塞进怪装置、自己变成装置的一部分。

## 静态隐喻 → 动态改写（视频特有）

静态配图的隐喻是一张"状态图"；视频隐喻必须是一个"状态变化"。每场回答：**开场是什么状态 → 中段发生什么干涉 → 结尾变成什么新状态？**

- 物件必须有可动部件：传送带要转、漏斗要漏、秤要摆、门要开、账单要飘、冰淇淋要化。
- 隐喻动词决定镜头动词：融化→缓慢推近+滴落特写；卡住→机械震动+挣脱；溢出→容器膨胀+漫过画面。
- 变形（小黑→物件→小黑）是合法的"状态变化"，且一场最多一次。
- 三拍模板直接套：`0–⅓` 建立初始状态；`⅓–⅔` 干涉/升级/转化；`⅔–结束` 高潮 + 为下一场留下交接物。

## 基础结构类型（选一种，不混搭）

| 类型 | 适合 | 动态化建议 |
|---|---|---|
| Workflow 流程 | 输入→处理→输出 | 传送带运转、管道流通、小黑在中间工位加工 |
| 系统局部 | 过滤器/数据库/渲染器局部 | 只画 3–5 个模块，其中一个卡住或溢出 |
| 前后对比 | 混乱/有序、手动/自动 | 左侧持续崩塌、右侧稳定运转，橙色箭头搬运 |
| 角色状态 | 痛点、焦虑、卡住到跑起来 | 2–4 个状态连续演变，小黑逐格变化 |
| 概念隐喻 | 内容工厂、信息仓库 | 一个大怪物件持续运转，一个输入一个输出 |
| 方法分层 | 框架、层级 | 小黑逐层搬砖搭建，上层搭好下层亮起 |
| 地图路线 | 路径、阶段 | 小黑沿弯路行走，节点依次激活 |
| 小漫画分镜 | 失败到成功、真实过程 | 2–4 个连续小场景，一格一个动作 |

## 反复刻规则

以下为已知旧构图（来自 ian-xiaohei-illustrations 案例与本技能示例）。同类主题必须换新隐喻，除非用户点名复刻：

- 传送带两个断点（素材箱/没承接）
- 小黑在内容机器里拉判断杆
- 小黑变漏斗分拣流量/信任/转化
- 小黑切素材鱼 / 一个纸团压成多种形状
- 小黑牵承接路径接到门把手
- 三层抽屉信息源（外部信号/内部资产/用户反馈）
- 三个小黑拿喇叭/搭桥/开门
- 小黑盖章话术工具箱
- 小黑举牌看常见坑
- 本技能示例中的"融化的钱冰淇淋"（通货膨胀）

判断方法：保留核心意思，更换主物件或小黑动作，直到构图与上述全部不同。
