# Phase A · 导演提案合同

产出一份可读的制作提案，然后停下等确认。确认之前不写任何模型提示词。

## 先重写素材

- 提炼核心判断、认知转折、可用图解释的锚点；删掉重复和次要分支；不平均用力。
- 旁白 240–270 汉字（≈55–65 秒），六场，每场 35–50 字 ≈ 8–12 秒。短句、口语、算账感。
- 默认免费管线单场生成时长须在 4–12 秒内：场景时长 = 旁白实测时长 + 0.5s，向上取整。
- 「小黑场景」列的开场状态就是首帧图提示词的基础——写清开场时谁在哪里、画面里有什么。
- 保留素材的核心主张、名词和数字；不虚构研究、统计、引语和事实细节。
- 开场必须有钩子（反常识提问 / 具体选择题 / 痛点场景），结尾回扣核心信息。

## 提案头（按顺序）

1. 中文标题 + 英文参考标题
2. 核心信息与开场钩子
3. 规格：画幅（默认 9:16）、白底黑小黑、旁白语言（默认中文）、总字数与时长
4. 旁白声线：清晰、亲和、略快（默认女声 shaonv，语速 1.15）；全片同一音色
5. 四色语义规划：本场系列里橙色/红色/蓝色各自承担什么（黑色固定为结构与角色）
6. BGM 方向、情绪转折点、叙事弧（钩子→设定→机制→后果→实践→收束，或激励/商业弧）

## 分镜表（恰好六场）

| # | 时间 | 叙事职责 | 小黑场景 | 运动/镜头/转场 | 旁白（配音稿） | 批注规划 | 音效方向 |
|---|---|---|---|---|---|---|---|

每场要求：

- **小黑场景**：小黑在做什么（动作动词）+ 主物件（1–2 个低科技物件）+ 状态变化（开场状态→干涉→新状态）；标注是否使用变形（一场最多一次）。
- **三拍**：按实际时长分三段（如 10s = 0–3/3–7/7–10；12s = 0–4/4–8/8–12），写清每拍画面变化。
- **≥4 个视觉设备**：小黑动作、环境转化、具体隐喻物件、箭头/图示符号、粒子/液体/光、镜头推拉摇移、前景擦镜、匹配剪辑/形变、与另一角色或超大物件互动。
- **每 2–3 秒一次可感知变化。**
- **交接**：与下一场显式交接，双方状态都写出来（姿势/运动方向/形状/物件，如"绿币滚出画面右缘 ↔ 下场开场同一绿币滚入左缘"）。
- **旁白**：口语中文，句子边界自然，不硬凑字数。
- **批注规划**：0–3 处，每处 2–8 字，颜色按四色语义，位置写清（如"左上留白区，第 5 秒随价签对折弹出"）。全片合计 ≤12 处。

## 构图按画幅

- `9:16`：上下分层、纵深、垂直揭示，底部 15% 留字幕安全区。
- `16:9`：左中右调度、横向跟踪，负空间留给批注。

## 确认结尾

问用户：批准当前提案并生成六条提示词 / 修改某场或某段旁白 / 更改全局设定。全局变更作废当前批准。

## Phase A 检查

- 素材、画幅、旁白语言明确；主题为白底。
- 旁白 240–270 汉字 ≈ 55–65 秒；六场职责互不重复。
- 每场三拍 + ≥4 设备 + 旁白 + 批注规划 + 音效方向 + 与前后场的命名交接。
- 每场隐喻为本次新发明，未复刻任何已知构图（对照 metaphor-invention.md 清单）。
- 批注全片 ≤12 处且只在后期层；生成画面无文字。
- 不超过四色语义范围；无技术色号；无虚构事实。
