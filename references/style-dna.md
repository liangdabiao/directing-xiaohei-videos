# 风格 DNA（视频版）

## 一句话

纯白画布上的手绘怪诞动画：极简、留白、克制、冷幽默、产品草图感——像产品人在白纸上画的解释草图突然动了起来。

## 必须锁（写入每条生成提示词）

- 纯白画布：无米色、暖灰、纸纹、噪点、渐变、阴影、光效、3D 纵深。
- 黑色手绘细线为主：轻微抖动、不机械、不矢量、不厚重描边。
- 主体占画面约 40%–60%，保留大块安静留白（含叠字安全区）。
- 一场只讲一个核心动作、结构、状态或隐喻。
- 风格密度措辞（沿用已验证句式）：rapid scene changes, kinetic motion-graphic transformations, and frequent visual events, while preserving an identical character design, constant line weight, and strict temporal consistency。禁用 "rapid style changes"。

## 四色语义（固定，不自由选色）

| 颜色 | 用途 | 视频 |
|---|---|---|
| 黑色 | 小黑、结构线稿、主要物件 | 画布主体，永远最多 |
| 橙色 | 主流向、路径、箭头、A→B 移动 | 每场最多一组主流向 |
| 红色 | 警示、问题、结果、情绪点 | 只在冲突/后果/转折时刻出现 |
| 蓝色 | 补充说明、脑内状态、系统状态 | 可选；一场最多一处 |

宁少勿多。一场可以只用黑+橙。红色是稀缺资源，全片留给情绪顶点和关键结果。

## 文字规则（与配图版的关键差异）

配图版的中文手写批注是画面的一部分；视频版**生成画面内禁止任何文字**（字母、数字、汉字、界面、Logo 全部禁止）——视频模型渲染汉字极易出错字且无法局部修正。

批注的处理方式：Phase A 每场输出"批注规划"（2–8 字的词、颜色、出现时机、画面位置），Phase B 之后全部在剪辑阶段以手写风格字体贴字呈现。批注词要短、少、准：全片 ≤ 12 处。

## 绝对不要（画面与提示词双向禁止）

- 商业插画、精致扁平风、科技感 UI、真实截图。
- PPT 信息图、正式流程图、课程课件、整齐网格。
- 可爱卡通、儿童插画、吉祥物海报。
- 复杂背景、渐变、阴影、纹理、复古纸感。
- 把每个节点都解释清楚——留白就是表达。
- 任何形式的画面内标题。
